김민준 지원서 심사

HTML 폼 핵심 요소 레퍼런스

HTML Form 태그와 입력 요소 완벽 가이드

1. 텍스트 입력 (<input type="...">)

  • type="text": 성명 등 단문 텍스트 입력
  • type="email": 이메일 형식(@ 및 도메인) 자동 유효성 검사
  • type="password": 보안을 위해 입력값을 마스킹(*) 처리
  • type="tel": 전화번호 입력, 모바일에서 숫자 키패드 호출

2. 숫자 / 날짜 입력

  • type="number": 숫자만 입력 가능 (min="1" max="120" 범위 제한)
  • type="date": 브라우저 내장 달력 팝업으로 날짜 간편 선택

3. 선택 요소 (<fieldset>, <select>)

  • <fieldset> / <legend>: 연관된 입력 요소를 그룹화하고 테두리/제목 부여
  • type="radio": 동일 name 그룹 중 단 하나만 선택 (예: 성별 Male/Female)
  • type="checkbox": 다중 선택 지원 (예: 코딩, 음악, 여행 등 관심분야)
  • <select> / <option>: 드롭다운 목록 (지역, 대학교 선택)

4. 장문 입력 및 제어 버튼

  • <textarea rows="4" cols="40">: 하고싶은 말 등 다중 라인 장문 입력
  • type="submit": 폼의 입력 데이터를 수집하여 처리
  • type="reset": 폼의 모든 입력란을 초기 상태로 리셋
